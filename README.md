#  Portfólio Pessoal | Kailane Del Conti Cassiolato

Desenvolvi esse projeto para apresentar minha trajetória, evolução técnica e alguns projetos que construí como Desenvolvedora Full-Stack.

🔗 **[Acesse o portfólio online aqui]( )**

## Tecnologias Utilizadas

Este projeto foi construído focando em performance e componentização, utilizando a seguinte stack no Front-end:

*   **[React](https://reactjs.org/)**
*   **[Vite](https://vitejs.dev/)**
*   **[TypeScript](https://www.typescriptlang.org/)**
*   **HTML5, CSS3 & JavaScript**

## Estrutura e Funcionalidades

O portfólio foi dividido em seções para facilitar a navegação:

*   **Sobre mim:** Um resumo da minha transição e atuação profissional, minha formação em Análise e Desenvolvimento de Sistemas, e meios de contato.
*   **Experiência Profissional:** Linha do tempo detalhando minhas experiências profissionais e o período de cada um.
*   **Habilidades:** Organização visual das ferramentas em que já trabalhei, desde Front-end até Back-end e Bancos de Dados.
*   **Projetos:** Apresentação de alguns sistemas que desenvolvi, com foco em automação e soluções operacionais.
